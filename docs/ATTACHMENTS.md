# 附件清单与登录限制

## 一、结论

| 项目 | 数值 |
| --- | --- |
| 范围 | 英语一 2010–2025（16 篇年份文档） |
| 附件数量 | **128 个 HTML**（每年 4 篇 × 做题/复盘 2 种） |
| 附件总体积 | **约 393.4 MB**（单个 0.8–8.3 MB） |
| 附件正文是否公开 | **否**。匿名请求返回 `302 → /login`，必须登录语雀 |
| 本站是否包含附件正文 | **否**（不登录、不绕过访问控制、不转存） |
| 可公开获取的信息 | 文件名、大小、原始链接、所属年份/篇目/模式 |

因此本站是一个**目录 + 资料索引 + 离线说明**的 PWA；128 份资料的正文需要你登录语雀后，从年份页的原始链接打开。

## 三、匿名访问抽样

| 附件 | HTTP | 跳转 | 判定 |
| --- | --- | --- | --- |
| `2010_text1_做题模式.html` | 302 | `/login` | 需登录 |
| `2015_text2_复盘模式.html` | 302 | `/login` | 需登录 |
| `2025_text4_做题模式.html` | 302 | `/login` | 需登录 |

验证方法：匿名 GET、禁止自动跟随跳转（`redirect: 'manual'`），时间 2026-11-03。
完整记录见 `raw/manifest.json → attachments.access`。

补充：yuque-dl 下载时对每个附件都输出 `need token`，与本结论一致。

CSV 列：`年份, 篇目, 模式, 文件名, 大小(字节), 原始链接, 访问状态`。

## 五、如果你想离线看附件正文

合法途径有两条，任选其一：

1. **在线查看**：登录语雀，点年份页里的附件链接。
2. **自建本地镜像（需你自行确认授权）**：
   - 把你已合法下载的 HTML 放到 `content/public/attachments/<年份>/文件名.html`；
   - 重新 `pnpm build`；
   - SW 已内置 `/attachments/` 的运行时 `CacheFirst` 规则，**打开过的**附件会缓存一年，可离线查看。
   - 注意：不要在未授权的情况下分发这些文件；仓库默认不含任何附件正文。

## 六、为什么不自动抓取

- 语雀对附件下载强制登录，本项目明确**不登录、不索取账号/密钥**。
- 绕过访问控制可能违反平台条款与著作权；技术上也涉及会话伪造，不应做。
- 公开页面本身只有附件卡片，没有正文文字或图片，故“抓取失败”不是脚本问题。
