## 三、附件是怎么拿到的

1. 语雀对 `/attachments/**` 的匿名请求统一 `302 → /login`（抽样记录见下），普通爬虫拿不到正文。
2. 本项目**没有绕过登录**。维护者在本机弹出独立 Chrome 窗口，**本人**登录语雀；
3. `scripts/fetch-attachments.mjs` 通过 CDP 读取该浏览器的会话来下载 128 个文件——密码只输入在浏览器中，脚本不读取、不保存、不上传。
4. 下载后核对大小并写入 `raw/attachments/<年份>/`，构建时原样复制到站点，访问者无需登录。

验证时间：2026-11-03；方法：匿名 GET、禁止自动跟随跳转。
该结果说明：**语雀原站需要登录**，本站的免登录阅读依赖已下载的副本。

## 四、怎么在站内阅读

- 年份页 → 点「做题模式 / 复盘模式」文件名 → 全屏阅读器（顶部有「← 返回」「原始文件」）。
- 原件是自包含 HTML（数据与图片都内联在文件里），没有外部依赖，iframe 可直接渲染。
- 单个文件 0.8–8.3 MB，首次打开需下载；之后进入 `kaoyan-local-attachments` 缓存，断网可重开。
- 年份页「缓存本年资料」可一次性缓存 8 份（约 24 MB），适合提前离线。
- 全部 128 份约 393 MB，**不做**壳层预缓存，避免安装时占用过大空间。

## 六、版权与传播

- 原件版权归原作者及权利人所有；本项目仅做个人离线阅读与检索，**未改写内容**。
- 站点已设置 `noindex` / `robots.txt Disallow`，避免被搜索引擎扩散；但 GitHub Pages 是公开 URL，拿到链接的人仍可访问。
- 若权利人认为不妥，删除 `attachments/` 下对应文件即可移除。
- 请勿将本站用于公开传播、售卖或二次分发。
