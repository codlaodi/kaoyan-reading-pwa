使用与安装 ​

添加到主屏幕（安卓 · Chrome / Edge） ​

  1. 用 Chrome（或 Edge、三星浏览器）打开本站地址（必须是 HTTPS，本地调试的 localhost 除外）。
  2. 点右上角 ⋮ 菜单 → 添加到主屏幕 / 安装应用。
  3. 确认名称后点「添加」，桌面会出现图标；从图标打开即为全屏独立窗口。
  4. 首次打开后停留几秒，让 Service Worker 完成预缓存（约几 MB）。

若菜单里没有「安装」，请确认：地址是 HTTPS、没有使用无痕模式、且已刷新过一次页面。

站内阅读资料 ​

  • 进入任一年份页 → 点「做题模式 / 复盘模式」文件名。
  • 打开的是资料原件（独立 HTML），阅读器顶部有「← 返回」和「原始文件」。
  • 不需要语雀账号，本站已托管原件。
  • 第一次打开需要联网（单个文件 0.8–8.3 MB）；打开后会自动进入缓存，断网再开同一份仍可读。
  • 想提前离线：在年份页点「缓存本年资料（约 24 MB）」，等进度完成即可。

离线阅读 ​

  • 预缓存范围：所有页面、脚本、样式、字体、图标、Pagefind 搜索索引。
  • 安装后首次访问会把站点外壳写入缓存；之后断网打开，目录、年份页、使用说明与搜索结果均可正常使用。
  • 资料原件（128 个 HTML，共约 393 MB）不在初始预缓存内，避免安装时占用过大空间： 读过的单份会自动缓存，也可在年份页整年下载。
  • 想确认是否已缓存：断网后从桌面图标打开，能进入首页即成功。

全文搜索 ​

  • 点顶部（手机为底部工具条）的「搜索」，或按键盘 Ctrl + K。
  • 输入中文关键词，如「2010」「Text 3」「复盘」「长难句」。
  • 搜索完全在本地进行，不上传任何内容。

阅读进度与字号 ​

  • 滚动阅读时顶部进度条会显示当前进度；离开页面时自动记住位置。
  • 下次回到首页，点「继续上次阅读」即可跳回；进入该页时右下角也会出现续读提示。
  • 顶部「A- / A+」调节正文字号，手机底部工具条同样可以调；设置只保存在本机浏览器。
  • 深色模式：右上角图标切换（跟随系统或手动）。

常见问题 ​

Q：打开资料要登录语雀吗？ A：不需要。128 份 HTML 原件已经下载并托管在本站，访问者直接点开即可。

Q：为什么第一次打开资料要等？ A：单个文件 0.8–8.3 MB，首次需要下载；下载后会进缓存，之后离线也能打开。年份页可整年缓存。

Q：需要注册或登录本站吗？ A：不需要。本站是纯静态站点，没有后端、没有账号体系，也不会上传任何数据。

Q：换手机后进度还在吗？ A：不在。所有偏好与进度都保存在当前浏览器的 localStorage 中，不跨设备同步，也不会离开你的手机。
